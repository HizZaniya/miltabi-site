# みるたび プライバシーポリシー

施行日: 2026 年 11 月 2 日

このポリシーは、Windows 向けの旅行の計画アプリ「みるたび」（以下「本アプリ」）が、利用者の情報をどう扱うかを定めたものです。

## 集める情報

開発者は利用者の個人情報を集めません。本アプリが利用者の情報を開発者へ送ることもありません。

本アプリには、アカウントの登録、利用状況の計測（テレメトリー、アナリティクス）、広告、クラッシュの自動送信、更新の自動確認の機能がありません。

## 通信

本アプリがインターネットと通信するのは、次の3つの場合だけです。どの場合も、通信の相手には、ふつうのインターネットの通信と同じく、利用者の IP アドレスが伝わります。

### コンシェルジュ（Anthropic の Claude）

旅程を組むコンシェルジュは、Anthropic の Claude で動きます。利用者が旅程を組むよう頼んだとき、本アプリは次の計画の内容を Claude に渡します。

- 計画の条件: 出発地、帰着地、日付、出発と帰着の時刻、人数（大人、子ども、乳幼児の数）、予算、費用と時間のどちらを優先するか
- 行きたい場所・やること: 名前、種類、優先度、場所、お土産の品、イベントの日時
- これまでに調べた結果と割引
- 組み直すときは、利用者が固定、追加、変更した予定と、空きなしにした予定（名前、場所、所要時間、費用、予約の要否、注意など）

計画の名前、予定に書いたメモ、住所、公式サイトの URL、予約番号、持ち物リスト、しおりの表紙の写真は、Claude に渡しません。

Claude へのつなぎ方は設定の画面で利用者が選びます。

- API キー: 本アプリが、Anthropic の API（<https://api.anthropic.com>）へ、計画の内容と利用者の API キーを送ります。設定の画面でつながるかを確かめるときは、API キーだけを送ります。
- Claude Code CLI: 本アプリは、利用者がこの PC に入れてログインした Claude Code を起動し、計画の内容を渡します。Anthropic へ送るのは Claude Code です。本アプリは Claude Code の認証情報を読まず、保存しません。会話を保存しないよう指定して Claude Code を起動します。

コンシェルジュの調べもののために、本アプリがほかの Web サイトへ接続することはありません。

Anthropic へ送った情報の扱いには、Anthropic のプライバシーポリシーと、利用者が Anthropic と結んだ契約（API の規約やサブスクリプションの規約）が適用されます。料金も、利用者が Anthropic との契約で払います。開発者は、Anthropic へ送った内容を受け取りません。

### 地図（OpenFreeMap）

本アプリは地図を表示するときに、OpenFreeMap（<https://tiles.openfreemap.org>）から地図のデータと文字の形を取得します。旅程が変わったあとに、しおりの日ごとの地図を描くときも同じです。取得するデータの範囲から、地図に表示している地域が OpenFreeMap に伝わります。

オフライン用の地図を保存するときは、旅程の場所の周りの地図のデータを、OpenFreeMap からまとめて取得します。このとき、本アプリの名前と版を送ります。計画の内容や場所の名前は送りません。

OpenFreeMap が扱う情報には、OpenFreeMap のプライバシーポリシーが適用されます。

### 移動の道の形（FOSSGIS の経路検索）

本アプリは、徒歩、バス、車、タクシーの移動の線を道に沿って地図に引くため、ドイツの FOSSGIS e.V. が運営する経路検索のサービス（<https://routing.openstreetmap.de>）に、移動の道の形を問い合わせます。問い合わせるのは本アプリが開いているあいだだけで、計画を開いたときと、旅程を組んだり組み直したり、移動を変えたりしたときです。答えは計画のデータに残します。移動の出る所、着く所、手段が変わらないあいだは、答えを残した移動をもう一度問い合わせることはありません。

問い合わせで送るのは、次のものだけです。

- 移動の出る所と着く所の緯度と経度。宿を出る移動や宿に着く移動では、宿の位置が含まれます
- 経路の種類（徒歩か車か）
- 本アプリの名前と版

計画の名前、場所の名前、メモは送りません。

FOSSGIS は経路の問い合わせをサーバーのログに残します。FOSSGIS のプライバシーポリシーによると、ログに残るのは、アクセスした機器のホスト名、時刻、ブラウザーの種類と版、OS、参照元の URL です。ログを残す期間は書かれていません。FOSSGIS が扱う情報には、FOSSGIS のプライバシーポリシー（[https://www.fossgis.de/datenschutzerklärung/](https://www.fossgis.de/datenschutzerkl%C3%A4rung/) 、ドイツ語）が適用されます。

道に沿った線を出している地図の「地図を直す」を押すと、OpenStreetMap の地図の誤りを知らせるページ（<https://www.openstreetmap.org/fixthemap>）を、既定のブラウザーで開きます。本アプリからは何も送りません。開いたページには OpenStreetMap のプライバシーポリシーが適用されます。

## この PC に残すもの

本アプリは次のものをこの PC に保存します。どれも、上の「通信」に書いたもののほかは外部へ送りません。

- 計画のデータ: 計画の名前、計画の条件、行きたい場所・やること、旅程、予約の状態と予約番号、持ち物リスト、注意を確かめたかどうか
- しおりの表紙の写真: 利用者が選んだ写真を、そのまま保存します。写真のファイルに撮影の日時や場所の情報が含まれていれば、それも残ります
- しおりの日ごとの地図の画像: 旅程から描いた地図の画像を、日ごとに1枚、計画のフォルダに保存します。旅程が変わって描き直したときは、古い画像を消します
- オフライン用の地図: 保存した地図のデータ
- 調べた結果: コンシェルジュが調べた営業時間、料金、予約の仕方などと、その出どころ
- 設定: Claude へのつなぎ方、画面の明るさ（ライトとダーク）、表示言語
- 画面の状態: 最後に開いたタブ。画面の表示に使う WebView2 が、表示に使ったデータを一時的に保存することもあります

計画のデータを新しい形式に移すときは、移す前のファイルを同じフォルダに残します。

これらは Windows のユーザーごとのアプリデータのフォルダの中にある、本アプリ用のフォルダにあります。そのフォルダを消せば、保存したものも消えます。

API キーはファイルには書かず、Windows の資格情報マネージャーに保存します。設定の画面から、いつでも消せます。

本アプリはログのファイルを作りません。

しおりを HTML や PDF に書き出したときは、利用者が選んだ場所にファイルを書き込みます。本アプリがこのファイルを外部へ送ることはありません。

## 本アプリが持たない情報

持ち主や同行者の名前と、家族の連絡先は、本アプリに入れる欄がありません。しおりには、手で書き込む空欄だけを刷ります。そのため、これらは保存したファイルにも、Claude に渡す内容にも、書き出したしおりにも入りません。

## Microsoft のコンポーネントとストア

本アプリは画面の表示に Microsoft Edge WebView2 を使います。Microsoft Store から入手した場合、インストールと更新は Microsoft Store が行います。WebView2 と Microsoft Store が扱う情報には、Microsoft プライバシー ステートメントが適用されます。

## 子どもの情報

本アプリは人数の一部として子どもと乳幼児の数を Claude に渡します。子どもの名前などの個人情報は集めません。

## ポリシーの変更

本アプリの動作が変わり、このポリシーの内容と合わなくなったときは、このページを更新し、施行日を改めます。
